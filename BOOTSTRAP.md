# D-VISTA / BOOTSTRAP

```text
Installation medium:     this document
Target architecture:     human prospective memory
Installation privilege:  voluntary attention
Service availability:    scheduled downtime only
Estimated install time:  90 seconds
```

D-VISTA ships without an executable. No binaries are shipped. The installation
medium is this document. Reading it carefully, once, while awake, is the
installation.

## Phase 0 — Install (awake)

1. **Observe the medium.** If a Linksys WRT54GS is available, pick it up or
   look at it: two antennas, blue and black case, a row of indicator lights.
   If not, picture any wireless access point you have seen. It does not need to
   be powered. Nothing is configured.
2. **Load the rule.** Say it once, slowly:

   > **When I notice I have Wi-Fi, I check whether I'm dreaming.**

3. **Run one honest check.** Ask, seriously, *"Am I dreaming?"* Where am I? How
   did I get here? What was I doing ten minutes ago? Answer accurately:
   **"No. I am awake."** That answer is correct, and the check is working.

## Phase 1 — Prepare the runtime (awake, eyes closed)

4. **Rehearse three settings.** About fifteen seconds each:
   - your bedroom, with one detail out of place;
   - a building you have never been in;
   - somewhere with **no router, no phone, no computer**: a field, a beach, an
     empty street. Nothing shows it, but you simply *know* Wi-Fi is available.

   In each one: notice the Wi-Fi, ask the question, notice what doesn't fit,
   and realize: **"This is a dream."**

5. **Release.** Stop rehearsing. Go to sleep normally. A good night's sleep
   matters more than a lucid dream. No alarm is required and none should be
   set.

## Phase 2 — Deferred activation (asleep, not guaranteed)

6. If, in a dream, you become aware that Wi-Fi is available, in any form or in
   no visible form at all, the rule may come back. Ask the question. Check the
   situation. The session opens **only if you recognize that this is a dream**.
   A dream that merely contains Wi-Fi is not a session.

   If it opens: stay calm, look around, attempt one simple action.

## Phase 3 — Log (awake again)

7. On waking, before anything else, write down what you actually remember. Note
   separately whether Wi-Fi appeared and whether you knew you were dreaming.

## Operator note

The dreaming mind may produce a network, a terminal, or this repository being
pulled from GitHub. That is your own memory reconstructing something you read
while awake. The source was read before the operator went offline. No physical
network traffic crosses the sleep boundary.

Nothing is installed in your brain except what you deliberately chose to
remember. Do not cut sleep short, disable medical alerts, or treat anything a
dream shows you as information from an outside system. The plain-language
explanation is in [IMPLEMENTATION.md](IMPLEMENTATION.md);
the full bedtime procedure is [RUNBOOK-TONIGHT.md](RUNBOOK-TONIGHT.md).
