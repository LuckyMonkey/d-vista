# Reference Hardware and Environmental Controls

## WRT54GS

The Linksys WRT54GS is the reference **waking mnemonic anchor**. Its recognizable antenna arrangement, chassis, and status indicators provide a repeatable object for short pre-sleep rehearsal. **Radio transmission is not part of the proposed induction mechanism.** Hardware is optional.

| Property | D-VISTA implementation |
| --- | --- |
| Power | May remain off |
| WAN uplink | Not required |
| SSID | No specific name needed |
| Firmware | Leave unchanged |
| Configuration | No factory reset, flashing, routing, packet capture, or network reconfiguration |
| Position | Safe, dry surface away from bedding |
| Effect claimed | Multisensory waking association only |

The model has multiple hardware revisions. D-VISTA does not depend on PCB type, storage capacity, antenna gain, radio modulation, or any specific firmware build. Do not enable insecure legacy WLAN settings merely to support the protocol.

## Minimal setup

1. During ordinary waking hours, look at or briefly handle the unit.
2. State the intention: **“When I notice I have Wi-Fi, I check whether I'm dreaming.”**
3. Imagine one situation in which no router, screen, or phone is visible, yet wireless connectivity is understood to be present.
4. Set the router down safely and follow the short, normal bedtime rehearsal.
5. Do not use the router's lights, heat, RF output, or wiring as overnight stimulation.

## Optional measurement equipment

A notebook or offline text note suffices for first-person observations. A phone voice recorder may help capture immediate morning recollection when convenient; avoid bright bedtime screens. Consumer devices cannot substitute for clinical polysomnography.

If an independent laboratory study is eventually commissioned, documented EEG/EOG/EMG acquisition, consent, and sleep-scoring methodology would be prerequisites. The hardware in the study would primarily **measure sleep and response timing**, rather than network traffic.
